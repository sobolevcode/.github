# 🌍 Welcome to SobolevCode (English)

We develop custom applications and utilities for LG smart TVs based on webOS. 
Our goal is to create convenient tools that expand the capabilities of your TV.

## 🌟 Main Projects

* **[ProxyTune](https://github.com/sobolevcode/ProxyTune)** — The ultimate VPN client (Xray / AmneziaWG) featuring a mobile remote control for seamless access to global content and bypassing restrictions.
* **[Homebrew Repository](https://github.com/sobolevcode/sobolevcode.github.io)** — Our official catalog for direct application installation.

## 📥 How to install our apps?
Simply add the link to our store in the Homebrew Channel settings on your TV (Root required):
`https://sobolevcode.github.io/repo.json`

*(Mirror: `https://sobolevcode.vercel.app/repo.json`)*

# 🇷🇺 Добро пожаловать в SobolevCode (Русский)

Мы разрабатываем авторские приложения и утилиты для смарт-телевизоров LG на базе webOS. 
Наша цель — создавать удобные инструменты, которые расширяют возможности вашего ТВ.

## 🌟 Главные проекты

* **[ProxyTune](https://github.com/sobolevcode/ProxyTune)** — ультимативный VPN-клиент (Xray / AmneziaWG) с мобильным пультом управления для комфортного обхода блокировок.
* **[Каталог Homebrew](https://github.com/sobolevcode/sobolevcode.github.io)** — наш официальный репозиторий для прямой установки приложений.

## 📥 Как установить приложения?
Просто добавьте ссылку на наш магазин в настройки Homebrew Channel на вашем телевизоре (требуется Root):
`https://sobolevcode.github.io/repo.json`

*(Зеркало: `https://sobolevcode.vercel.app/repo.json`)*
